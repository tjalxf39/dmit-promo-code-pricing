## 优惠码怎么用：三步，别跳

1. 在购物车页面选好机房、线路和具体档位，确认配置。
2. 选择计费周期——这一步很关键，多数码对月付无效。
3. 在结算页找到优惠码输入框，填入代码，点 **Validate Code**。价格会当场刷新，通不过会直接给提示。

有几个细节值得提前知道：

- 优惠码通常**只能用于新订单**，且不能和其他折扣叠加。
- 带 `RECURRING` 字样的码是循环折扣，也就是续费同价，不是首年特价，这一点比很多商家的「首年骨折」实在。
- 带 `NON-MONTHLY` 字样的码，月付一定用不了。
- 支付方式支持支付宝、PayPal 和信用卡。用支付宝付款的一个附带好处是退款不额外扣手续费，开机测试不满意时脱身成本更低。

## Pro、EB、T1 到底怎么选

抛开参数，这三条线的差异其实就一句话：你多花的钱，买的是国内访问质量。

| 国内访问 | 最好 | 中等偏上 | 不优化 |
| 同档价格 | 高 | 中 | 低 |
| 流量额度 | 少 | 多 | 最多 |
| 适合 | 建站、面向国内用户的应用 | 预算有限但想要部分优化 | 中转、海外业务、大带宽需求 |

具体到场景：

- **只做面向国内的博客或小站**，从 Pro.TINY 起步就够，1 核 2GB、1TB 双向流量、1Gbps 端口，$10.90/月，属于这一档里门槛较低的选择。
- **预算优先、对国内延迟不敏感**，T1.WEE 年付 $36.90 是洛杉矶的最低入手价，1 核 1GB 加 4Gbps 端口。拿来跑中转、监控、海外业务都合适，别指望它给你国内访问体验。
- **想要部分优化又想省钱**，EB 系列比 Pro 便宜、回程走 CMIN2/AS9929，属于折中方案。注意 EB 的季度及更长周期有 8 折循环码，折后价格差拉得更开。

还有一个容易被忽略的官方提示：DMIT 明确说过洛杉矶 AS3 平台仍在持续优化阶段，磁盘性能和 SLA 可能低于成熟平台。如果你要跑对 IO 敏感的生产业务，先开一台短周期测试再决定，比直接上年付稳妥。

## 库存和补货是怎么回事

DMIT 缺货是常态，不是偶然。它的机器多来自自持带宽和特定线路资源，补货节奏由上游决定，一次性放完就没了。近期的补货规律大致是：

- 每次集中在某个平台（比如 AS3）全量上架，售罄后下次时间不确定；
- 消息通常先在官方 Telegram 频道和社区发出，在放出后的一两个小时内被抢完；
- 补货往往同时覆盖洛杉矶和香港，但香港 Eyeball 已经下线，可选范围比过去窄。

所以看到「有货」别习惯性拖几天，尤其低价档位（TINY、WEE）通常是第一批没的。

## 几个常见问题

**优惠码填了没反应怎么办？**
先检查付款周期。绝大多数码对月付无效，这是最常见的失效原因；其次确认产品线是否匹配，T1 的码拿去买 Pro 一定通不过。

**优惠码可以叠加吗？**
通常不行。官方公告里一般会写「不可与其他折扣或特殊优惠同时使用」，结算页只会认一个。

**超了流量会停机吗？**
不会。DMIT 的做法是降速不限流，不同档位降到的带宽不一样，最低 4Mbps，最高可以保留到 1Gbps。

**支持哪些付款方式？**
支付宝、PayPal、信用卡。用支付宝下单时，退款流程和手续费都更简单一些。

**年付一定比月付划算吗？**
不绝对。年付本身有周期折扣，再叠上循环优惠码通常更便宜；但如果你只有短期需求，或者要测试线路质量，先用月付跑一轮再转年付也不吃亏。
